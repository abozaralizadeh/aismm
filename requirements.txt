# --- Tracing ---
# Routes the Agents SDK tracer into LangSmith (SandBox/ComicBook pattern). Inert
# unless LANGCHAIN_API_KEY is set, so it is a hard dep like in SandBox — the tool
# being merely "optional" is why traces silently never appeared.
# 0.13+ ingests through `POST /runs/multipart`. Older SDKs post to
# `POST /runs/batch`, which LangSmith has DEPRECATED (disruption from 31 Jan
# 2027) — that is what the "calls to a deprecated API endpoint" banner in the
# LangSmith UI was reporting. The floor is what fixes it: a fresh install on a
# lower pin would quietly go back to the old endpoint. The client still falls
# back to /runs/batch when a server does not advertise
# `batch_ingest_config.use_multipart_endpoint`, so self-hosted stays supported.
langsmith>=0.13.0
